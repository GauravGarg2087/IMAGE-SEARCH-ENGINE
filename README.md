# Image Search Engine

A simple image search engine built using **HTML, CSS, and JavaScript** with the **Unsplash API**.

## Live Demo

https://image-search-engine-bygg.netlify.app/

## Features

* Search for images using keywords
* Fetches images from the Unsplash API
* Displays results in a responsive grid
* Hover effects on image cards
* Show More button to load additional results
* Responsive layout for different screen sizes

## Technologies Used

* HTML
* CSS
* JavaScript
* Unsplash API

## How It Works

1. Enter a search term in the search bar.
2. The application sends a request to the Unsplash API.
3. Matching images are fetched from the API.
4. The results are displayed in a responsive grid.
5. Click **Show More** to load additional results.

## API

This project uses the **Unsplash API** to search for and retrieve images.
